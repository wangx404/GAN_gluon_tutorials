# Gluon生成对抗网络教程

本仓库是MXNet/Gluon生成对抗网络（GAN）英文教程的中文翻译，包含以下内容：

1. [生成对抗网络简介](./01_gan-intro_Introduction%20to%20GAN.ipynb)
2. [深度卷积生成对抗网络：生成人脸](./02_deep-convolutional-gan_generate%20human%20face.ipynb)
3. [条件生成对抗网络：按标签生成数字](./03_conditional-gan_generate%20digits%20with%20different%20labels.ipynb)
4. [像素到像素的生成对抗网络：使用U-Net转换图像](./04_pixel2pixel-gan_Unet%20to%20transform%20image.ipynb)

英文教程源自MXNet团队的[《The Straight Dope》](https://github.com/zackchase/mxnet-the-straight-dope)。本仓库基于较早版本的MXNet API，运行代码时可能需要相应的旧版依赖。部分训练参数仅用于快速演示；实际训练时可根据数据集和硬件调整训练轮数、批量大小及学习率。
